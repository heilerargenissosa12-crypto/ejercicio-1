# Ejercicio 1: Cook Your Lasagna

- **Concepto:** Basics (Sintaxis básica y métodos en Java)
- **Plataforma:** Exercism (Java Track)

## Descripción del Problema
Vas a cocinar una deliciosa lasaña. Tienes un libro de cocina con instrucciones precisas:
1. El tiempo esperado en el horno para la lasaña es de **40 minutos**.
2. Cada capa de lasaña toma **2 minutos** en prepararse.

## Tareas a Implementar en `Lasagna.java`:
1. `expectedMinutesInOven()`: Retorna el número de minutos esperado en el horno (40).
2. `remainingMinutesInOven(int actualMinutesInOven)`: Retorna cuántos minutos faltan restando el tiempo transcurrido del tiempo esperado.
3. `preparationTimeInMinutes(int numberOfLayers)`: Retorna cuántos minutos toma preparar las capas (capas * 2).
4. `totalTimeInMinutes(int numberOfLayers, int actualMinutesInOven)`: Retorna la suma del tiempo de preparación y el tiempo en el horno.

## Cómo ejecutar en Visual Studio / VS Code:
1. Abre este archivo o la clase `Main.java`.
2. Presiona el botón de **Run / Ejecutar** en la esquina superior derecha o usa `F5` / `Ctrl + F5`.
